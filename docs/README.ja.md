ActivityPlug ドキュメント
=========================

[English](README.md) | [한국어](README.ko.md) | 日本語

ActivityPlug は TypeScript ライブラリ、GraphQL・HTTP サーバ、ブラウザ向け
BFF route の 3 つの統合サーフェスを提供します。アプリケーションの境界に
合う経路から読み始めてください。
