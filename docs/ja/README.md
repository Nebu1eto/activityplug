ActivityPlug ドキュメント
=========================

[English](/en/README.md) | [한국어](/ko/README.md) | 日本語

ActivityPlug は TypeScript ライブラリ、GraphQL・HTTP サーバ、ブラウザ向け
BFF route の 3 つの統合サーフェスを提供します。アプリケーションに合う
経路から読み始めてください。
