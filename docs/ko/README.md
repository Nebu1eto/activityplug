ActivityPlug 문서
=================

[English](/en/README.md) | 한국어 | [日本語](/ja/README.md)

ActivityPlug는 TypeScript 라이브러리, GraphQL·HTTP 서버, 브라우저용 BFF
route의 세 가지 통합 표면을 제공합니다. 애플리케이션에 맞는 경로부터
읽으십시오.


시작하기
--------

 -  [시작 가이드](getting-started.md)는 설치에서 첫 번째 요청까지
    안내합니다.
 -  [핵심 개념](concepts.md)은 adapter, instance, session, capability,
    identifier, page, error를 정의합니다.
 -  [API 표면](api-surfaces.md)은 라이브러리, GraphQL, HTTP, 브라우저
    API를 비교합니다.
