0.1.0 인증 마이그레이션
=======================

ActivityPlug 0.1.0의 공개 API는 HTTP `Authorization` 헤더로만 세션을
받습니다. 이 변경은 세션 식별자가 URL, 요청 본문, 브라우저 기록, 로그,
리퍼러를 통해 유출되는 것을 방지합니다.


제거된 입력
-----------

계정 게시물, 팔로워, 팔로잉 조회, 게시물 및 게시물 기록 조회, 공개 및 로컬
타임라인, 검색, 투표 조회, 홈 타임라인 및 알림 WebSocket URL에서
`sessionId` 쿼리 매개변수가 제거되었습니다. 이제 모든 `/api/v1/**` URL의
`sessionId` 쿼리 매개변수는 거부됩니다.

모든 HTTP JSON 및 멀티파트 요청 본문에서 최상위 `sessionId` 필드가
제거되었습니다. 해당 필드가 있는 본문은 무시되지 않고 거부됩니다.

GraphQL의 `accountFollowers`, `accountFollowing`, `accountPosts`,
`accountRelationship`, `filter`, `filters`, `followRequests`, `homeTimeline`,
`list`, `listAccounts`, `listTimeline`, `lists`, `notificationUnreadCount`,
`notifications`, `poll`, `postHistory`, `publicTimeline`, `scheduledPost`,
`scheduledPosts`, `viewer`, `acceptFollowRequest`, `authRefresh`, `authRevoke`,
`blockAccount`, `bookmarkPost`, `clearNotifications`, `deleteFilter`,
`deleteList`, `deletePost`, `deleteScheduledPost`, `dismissNotification`,
`favouritePost`, `followAccount`, `rejectFollowRequest`, `unblockAccount`,
`unbookmarkPost`, `unboostPost`, `unfavouritePost`, `unfollowAccount`,
`unmuteAccount`에서 `sessionId` 인수가 제거되었습니다. `notificationStream`과
`timelineStream`에서도 제거되었습니다.

GraphQL 입력 객체 `BoostPostInput`, `CreateFilterInput`, `CreateListInput`,
`CreatePostInput`, `DeleteMediaInput`, `ListAccountInput`, `MuteAccountInput`,
`ReactPostInput`, `SchedulePostInput`, `SearchInput`, `UpdateFilterInput`,
`UpdateListInput`, `UpdateMediaInput`, `UpdatePostInput`, `UpdateProfileInput`,
`UpdateScheduledPostInput`, `UploadMediaFromUrlInput`, `UploadMediaInput`,
`VotePollInput`에도 더 이상 `sessionId`가 없습니다.


0.1.0 이전
----------

~~~~ http
GET /api/v1/timelines/home?sessionId=$ACTIVITYPLUG_SESSION HTTP/1.1
Host: proxy.example
~~~~


0.1.0 대체 방식
---------------

~~~~ http
GET /api/v1/timelines/home HTTP/1.1
Host: proxy.example
Authorization: Bearer $ACTIVITYPLUG_SESSION
~~~~

GraphQL HTTP 요청도 같은 Bearer 헤더를 사용하며 인수와 입력 객체에서
`sessionId`를 생략합니다. WebSocket 업그레이드도 Bearer 헤더를 사용하며
WebSocket URL의 자격 증명은 거부됩니다.

브라우저 애플리케이션은 `/v1/browser/**`와 불투명 BFF 쿠키를 사용해야
합니다. ActivityPlug 세션 ID를 읽거나 저장하면 안 됩니다. URL은 기록,
로그, 리퍼러를 통해 유출될 수 있으므로 쿼리 자격 증명 호환 별칭은 제공하지
않습니다.
