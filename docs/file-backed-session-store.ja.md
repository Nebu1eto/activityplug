ファイルベースの認証セッションストア
====================================

ActivityPlug は、すべてのサーバーデプロイで同じ公開契約に従う
`AuthSessionStore` 実装をサポートします。既定の開発用実装は
`InMemoryAuthSessionStore` です。本番デプロイでは Redis や PostgreSQL など
のネットワーク型ストアを使用するべきです。

ファイルベースの認証セッションストアは推奨されません。認証セッションには、
リモートアクセストークン、リフレッシュトークン、origin メタデータ、アカウント
識別子が含まれます。通常のファイルは、専用のセッションバックエンドよりも
ローテーション、アクセス制御、バックアップ、同時書き込み、インシデント対応を
難しくします。

ファイルストレージは、ローカル実験、単一ユーザーのプロトタイプ、オフライン統合
テストでは有用な場合があります。将来追加する場合は、同じ `AuthSessionStore`
契約を実装し、可能な限り安全でないファイル権限を拒否し、本番の既定値ではない
ことを文書化しなければなりません。
