파일 기반 인증 세션 저장소
==========================

ActivityPlug은 모든 서버 배포에서 같은 공개 계약을 따르는
`AuthSessionStore` 구현을 지원합니다. 기본 개발용 구현은
`InMemoryAuthSessionStore`입니다. 프로덕션 배포에서는 Redis나 PostgreSQL 같은
네트워크 기반 저장소를 사용해야 합니다.

파일 기반 인증 세션 저장소는 권장하지 않습니다. 인증 세션에는 원격 접근 토큰,
갱신 토큰, origin 메타데이터, 계정 식별자가 포함됩니다. 일반 파일은 전용 세션
백엔드보다 회전, 접근 제어, 백업, 동시 쓰기, 사고 대응을 더 어렵게 만듭니다.

파일 저장소는 로컬 실험, 단일 사용자 프로토타입, 오프라인 통합 테스트에는 유용할
수 있습니다. 추후 추가한다면 같은 `AuthSessionStore` 계약을 구현해야 하며,
가능한 경우 안전하지 않은 파일 권한을 거부하고 프로덕션 기본값이 아님을
문서화해야 합니다.
