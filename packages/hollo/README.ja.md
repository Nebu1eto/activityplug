@activityplug/hollo
===================

[English](README.md) | [한국어](README.ko.md) | 日本語

ActivityPlug 用の Hollo アダプターです。


インストール
------------

~~~~ sh
pnpm add @activityplug/hollo
~~~~

Node.js 26 以降が必要です。このパッケージは ECMAScript モジュールを使用します。


使用方法
--------

~~~~ ts
import * as activityplug from "@activityplug/hollo";
~~~~

パッケージルートは、サポートされる公開 API を公開します。このリリースで
利用可能な正確な契約については、エクスポートされた型を参照してください。
