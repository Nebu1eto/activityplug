@activityplug/session-Redis
===========================

English | [한국어](README.ko.md) | [日本語](README.ja.md)

Redis authentication session and lifecycle storage for ActivityPlug server mode.


Installation
------------

~~~~ sh
pnpm add @activityplug/session-redis
~~~~

Node.js 26 or newer is required. This package uses ECMAScript modules.


Usage
-----

~~~~ ts
import * as activityplug from "@activityplug/session-redis";
~~~~

The package root exposes the supported public API. Consult the exported types
for the exact contracts available in this release.
